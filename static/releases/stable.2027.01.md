## Stable version release 2027-01
A new stable version of the Energy Transition Model, `#stable.2027.01`, will be released on 10 December. This version is intended for use throughout 2027. A stable version is a frozen copy of the model: its assumptions and calculations remain unchanged after the release date, so any change in scenario outcomes results only from changes made to the scenario itself.

After release, `#stable.2027.01` will not receive improvements or bug fixes to the calculation model, or the frond-end. The regular, `#latest`, version of the ETM will continue to be updated as usual.

The current stable version, `#stable.2025.01`, will remain available after the release, and scenarios created in it will not be affected. `#stable.2027.01` includes all additions and improvements made to the model since then. For more information about model vesions, see the <a href="https://docs.energytransitionmodel.com/main/user_manual/model-versions" target="_blank">documentation</a>.

New scenarios can be created directly in `#stable.2027.01`. Existing scenarios can also be migrated from `#latest` to `#stable.2027.01`, but only during a short period after the release. The procedure for requesting a migration will be announced soon.

Sign up for the technical newsletter via your [profile settings](https://my.energytransitionmodel.com/identity/profile) to make sure you don't miss any updates. The newsletter is sent whenever the model is updated and usually includes a changelog of changed inputs and gqueries. In the coming period, it will also cover the stable version and the steps required to migrate scenarios between model versions.
