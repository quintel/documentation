### New features
#### Simplified heat and stock sliders for buildings and households

* The way the building and household stock is configured has been simplified: considerably fewer
sliders are now needed to set the housing and building stock and their heat demands. The same building
and household categories are still used. These changed sliders can be found here:
  * <a href="https://energytransitionmodel.com/scenario/demand/households/population-and-housing-stock" target="_blank">Population & housing stock</a>
  * <a href="https://energytransitionmodel.com/scenario/demand/buildings/building-stock" target="_blank">Building stock</a>
* Heat demand for buildings and households is no longer set with sliders in kWh/m2.
Instead, insulation and behaviour sliders determine heat demand, making it more intuitive to use.
This also reduces the total number of sliders as there is one insulation slider per construction period, instead of one per building type per construction period. The new sliders can be found here:
  * <a href="https://energytransitionmodel.com/scenario/demand/households/insulation" target="_blank">Households - insulation</a>
  * <a href="https://energytransitionmodel.com/scenario/demand/households/behaviour" target="_blank">Households - behaviour</a>
  * <a href="https://energytransitionmodel.com/scenario/demand/buildings/insulation" target="_blank">Buildings - insulation</a>
  * <a href="https://energytransitionmodel.com/scenario/demand/buildings/behaviour" target="_blank">Buildings - behaviour</a>

#### Adressed login issues

* Signing in now works across the whole ETM domain. Switching between the default interface and the Collections interface, or switching between model versions (latest or stable) does not prompt a new login request.

#### IPCC-based direct emissions reporting

* Direct emissions can now be read out per IPCC reporting category, in addition to the existing breakdown per ETM sector. This new breakdown is available in the chart overview.

<img src="/img/releases/direct_emissions_ipcc_chart.png" width="650" />

#### New emissions inputs

* New inputs have been added that allow users to adjust non-CO2 and non-energetic emissions. These can be set through the API but are not yet available as sliders in the front-end.

#### Retired Scenario tools
* The outdated Scenario tools that could be used to communicate with the API of the ETM has been
officially retired. It has been replaced by <a href="https://docs.energytransitionmodel.com/main/pyetm/introduction/" target="_blank">PyETM</a>, which is the modern, actively maintained Python package for interacting with the ETM API.

### Bug fixes
* When the weather year was changed from the default and a households stock slider was also changed, the space heating demand did not reflect the selected weather year for the changed stock group. Changing the stock slider prompted a calculation based on present year heat demand, overriding the weather year effect. This has now been corrected.
* The number of units for household batteries did not scale properly with the housing stock, which could lead to unexpected installed capacity and volume. This is now fixed.
